## ETF 项目迁移到 admin 管理后台

- 将 `apps/admin/ETF`（hushicai/ETF 网格交易策略，Snowpack + React 16 + styled-components）迁移为 `apps/admin/src/pages/Etf/` 下的页面模块。
- 侧边栏/路由新增：`config/routes.ts` 中 `/etf`（菜单"ETF管理"，icon lineChart）→ 子路由 `/etf/grid-strategy`（组件 `./Etf`）。
- 关键适配（原项目 React 16 → admin React 19）：
  - 移除 `findDOMNode`（React 19 已删除）：Suggestion 用 `containerRef.current` 判断点击区域。
  - 移除 `forwardRef/ForwardedTextInput`（Download 组件改用 `document.getElementById('fund-input')` 读值，无需 ref）。
  - `JSX.Element` → `React.JSX.Element`；`InputHTMLAttributes` 需要显式泛型参数 `<HTMLInputElement>`。
  - 样式从 styled-components 重写为 `antd-style` 的 `createStyles`（admin 已声明该依赖），统一样式在 `src/pages/Etf/styles.ts`，避免影响全局。
  - 去掉原全局 reset（createGlobalStyle 会污染整个后台），改为 wrapper 内局部 reset。
- 依赖替换（避免为迁移引入新依赖）：
  - `fetch-jsonp` → 自写 `src/pages/Etf/common/jsonp.ts`（天天基金接口不支持 CORS，仍走 JSONP，callback 参数名 `callback`）。
  - `downloadjs` → 原生 `<a download>`。
  - `html-to-image` 保留（通过 shamefully-hoist 解析，未在 admin package.json 中声明，属幽灵依赖，注意后续如卸载会破坏导出功能）。
- 验证：`tsc --noEmit` 中 ETF 相关 0 错误（项目本身有 539 个存量错误）；`max dev` + Playwright 冒烟测试页面正常渲染（19 行网格、菜单/面包屑正确）。
- 原 `apps/admin/ETF/` 文件夹未删除（git 未跟踪，删除不可逆），等用户确认后可清理。
